[Windows]
1. ZIP을 완전히 풉니다.
2. 게임을 저장하고 RPCS3를 완전히 종료합니다.
3. install.bat을 실행합니다.
4. 1(설치)을 입력하고 dev_hdd0가 들어 있는 RPCS3 폴더를 고릅니다.
5. "설치 완료"가 나오면 게임을 실행합니다.

[Linux]  xdelta3가 필요합니다 (sudo apt install xdelta3)
  sh install.sh install ~/.config/rpcs3

[되돌리기]
  Windows: install.bat 실행 후 3(복원)
