# 죠죠의 기묘한 모험 Eyes of Heaven 한글화 번역 지침

게임: PS3 『ジョジョの奇妙な冒険 アイズオブヘブン』(격투 액션). 대상 파일: `messageInfo_common` — 메뉴·시스템 문구, 캐릭터 이름, 스킬 이름, 도감(갤러리) 설명, 캐릭터 대사(스킬 발동 대사, 배틀 대사, 도감 대사)가 섞여 있다. 파일 순서대로 비슷한 종류가 모여 있으니 앞뒤 문맥을 참고한다.

## 1. 출력 형식

입력 파일의 각 줄 `{"id", "src"}` 마다 출력 파일에 한 줄씩, **입력과 같은 순서로 빠짐없이**:

```json
{"id": "0x12345678", "src": "<입력 src 그대로 복사>", "ko": "번역문", "state": "needs_review", "note": "초안(Claude)."}
```

- `src`는 입력에서 **한 글자도 바꾸지 말고** 그대로 복사한다 (반영 시 원문 지문을 대조함).
- `state`: 기본 `needs_review`. 아래 경우는 `needs_human_review`:
  - 미승인 용어(용어집 `state=unresolved`)를 쓴 경우 → note에 `미승인 용어: T0123, T0456`
  - 용어집에 없는 고유명사(인물·스탠드·기술·지명)를 옮긴 경우 → note에 `용어집 없음: 原文→번역`
  - 뜻이 확실하지 않거나 말장난 등으로 의역한 경우 → note에 이유
- `note`는 항상 `초안(Claude).`로 시작하고, 필요한 메모를 뒤에 붙인다.
- JSON은 UTF-8, `ensure_ascii=False`로. 줄바꿈은 JSON 문자열 안에서 `\n`.

## 2. 태그·기호 규칙 (기계 검사됨)

- `<string />`, `<string 1 />`, `<icon …>`, `<color …>…</color>`, `<system …>`, `<progress>` 등 **모든 태그는 개수 그대로 보존** (순서는 한국어 어순에 맞게 바꿔도 됨). 태그 안의 내용(`0xff4200ff` 등)은 절대 바꾸지 않는다.
- `<ruby 읽기>글자</ruby>` 루비는 빼도 되고 바꿔도 되지만, 쓰면 짝을 맞춘다. 보통은 루비를 빼고 한국어로 자연스럽게 옮긴다. 예: `「<ruby ジャスティス>正義</ruby>」` → `「정의(저스티스)」` 또는 `「저스티스」` — 스탠드명은 용어집 표기를 따른다.
- 「<１>」 같은 전각 숫자 괄호는 태그가 아니다.
- 줄바꿈(`\n`) 수는 원문과 **같게** 유지한다 (텍스트 상자 크기 때문). 한 줄이 원문 줄보다 눈에 띄게 길어지지 않게 한다.
- 전각 영숫자(`ＡＢＣ１２３`)는 반각(`ABC123`)으로. 전각 공백(`　`)은 원문 위치 그대로 둔다.
- 「」『』 괄호는 원문대로 유지한다. `！？`는 `!?`(반각)으로, `…`, `―`, `〜`는 그대로.
- `％`는 `%`로.

## 3. 용어 (반드시 지킬 것)

- `work/translate/glossary.tsv`(id, 일본어, 한국어, 상태; `python -I scripts/check_part.py --tsv work/translate/glossary.tsv`로 생성)를 따른다. **approved 표기는 그대로** 써야 한다(자동 검사됨). 긴 표기가 우선: `ジョセフ・ジョースター`는 `죠셉 죠스타`.
- 결정 사항:
  - 4부 東方仗助/仗助 = `죠스케`(히가시카타 죠스케). 8부 東方定助/定助 = 이름 칸·처음 소개에서 `히가시카타 죠스케(8부)`, 한 문장에 仗助와 함께 나오면 定助 쪽을 `8부 죠스케`로.
  - 1부 ディオ = `디오`, 3부 이후 ＤＩＯ = `DIO`.
  - スタンド使い = `스탠드 유저`. スタンド = `스탠드`.
  - 부 제목: `Ｐａｒｔ１`… → `Part1`… (5부 `Ｐａｒｔｅ５`도 `Part5`).
  - 이집트 9영신 스탠드는 `게브 신`, `바스테트 여신`, `호루스 신`, `오시리스 신`처럼 신/여신을 붙인다.
  - D4C: 영문명 `Dirty deeds done dirt cheap`는 영문 그대로(반각), 일본어 설명 `いともたやすく行われるえげつない行為`는 `더없이 손쉽게 자행되는 더러운 짓거리`.
  - 波紋 = `파문`, 吸血鬼 = `흡혈귀`, 石仮面 = `돌가면`. 柱の男 등 용어집에 있는 설정 용어는 용어집 표기를 따르고, 미승인이면 human_review.
- **의성어·효과음(擬音: ゴゴゴゴ, ドドドド, ズキュウウン, メメタァ, バーン 등)은 일본어 그대로 둔다** (사용자 결정). 웃음소리·감탄사(ガハハ, ウリィィ, 無駄無駄 등 대사)는 한국어로 옮긴다: `무다무다`·`오라오라`·`우리이이` 같은 정발 관용 표현을 쓴다(無駄無駄 → `무다무다`, オラオラ → `오라오라`, ＷＲＹＹＹ → `WRYYY`).

## 4. 문체

- 메뉴·시스템: 간결한 명사형/합쇼체 (`~합니다`, `~하시겠습니까?`).
- 스킬·기술 이름: 짧고 강하게, 명사형. 정발 기술명을 알면 그것을, 모르면 직역 + human_review.
- 도감 설명: 평서체 `~다.` 서술 (예: `Part5 『황금의 바람』의 등장인물.`).
- 캐릭터 대사: 정발 만화·국내 애니의 말투를 살린다. 캐릭터마다 어조 유지 (죠타로: 무뚝뚝한 반말; 죠셉: 가볍고 장난스러운 말투; DIO: 거만한 `~다`, `~하는 거다`; 죠르노: 존댓말 `~습니다` 등). 정발 표기를 확신할 수 없는 유명 말버릇(예: `やれやれだぜ`)은 자연스러운 한국어로 옮기고 human_review + note에 `말버릇 표기 확인`. 문장 끝 `ッ！`의 박력은 `~다!!`, `~라고!` 등으로.
- 유명한 대사는 정발/밈 표현을 존중 (예: `だが断る` → `하지만 거절한다`, `てめーは俺を怒らせた` → `넌 날 화나게 했다`).
- 일본어 존칭(さん·くん·様)은 문맥에 맞게: `~씨`, 생략, `~님`.

## 5. 작업 방법

1. 입력 파일을 끝까지 읽고, 출력 파일을 쓴다. 양이 많으면 여러 번에 나눠 이어 쓴다(덮어쓰지 말 것).
2. 다 쓴 뒤 검사: `python -I scripts/check_part.py <입력> <출력>` — 누락·순서·src 변경·태그·줄바꿈 수·approved 용어 위반을 보고한다. **문제 0건이 될 때까지 고친다.**
3. 최종 보고: 처리 건수, needs_human_review 건수, 용어집에 없어서 새로 옮긴 고유명사 목록(원문→번역), 판단이 애매했던 점.
